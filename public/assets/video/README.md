# Hero background video

Drop a theme-matched, royalty-free loop here as **`hero.mp4`** and the landing
hero will use it automatically. Until then, an animated CSS "aurora" gradient
(indigo/violet/blue) is shown as a graceful fallback — the page already looks
cinematic without a video.

Recommended free clip (no attribution, Mixkit License — indigo/violet gradient):
- https://mixkit.co/free-stock-video/purple-blue-gradient-101711/

How to add it:
1. Open the link, click **Download Free** (720p or 1080p).
2. Rename the file to `hero.mp4`.
3. Place it in this folder: `public/assets/video/hero.mp4`
   (and keep a copy in your Documents root if you like).

Tips: keep it < ~6 MB and a few seconds long for fast load; it is muted +
looped + `playsinline`, so any abstract/dark loop works well.
